How to add to Gmail

  1. Select the signature above — click just before the card, drag to select the entire table.
  2. Copy it (Cmd+C / Ctrl+C).
  3. Open Gmail → click the gear ⚙ top-right → See all settings.
  4. Go to General tab → scroll to Signature section.
  5. Click Create new, give it a name, then paste (Cmd+V) into the editor box.
  6. Scroll down and hit Save Changes.
  7. Compose a new email — your signature appears automatically.

How to add to Hashnode blog posts

  1. Open your Hashnode post editor.
  2. At the bottom of the post, click the / command menu → choose HTML block.
  3. Open this page's source (Cmd+U), copy everything between the comments SIGNATURE START and SIGNATURE END.
  4. Paste the HTML into the Hashnode HTML block.
  5. Readers on modern browsers will see the full styled signature with clickable links.
